# Lesson 13: Grammar: Waan vs Waxaan

Module: Greetings and Foundations
Suggested skills: `grammar_waan_vs_waxaan`, `subject_marker_choice`
Source material: `Chatbot_1.pdf`, pages 6-8 and 13-15

Focus
Teach the learner when to use `waan` for short direct sentences and `waxaan` for sentences with an object or extra phrase.

Why this lesson exists
The transcript repeatedly circles around `waan` versus `waxaan`. The learner needs a usable beginner rule that supports production. Avoid presenting this as the complete theory of Somali focus markers.

Prerequisites
- Present tense markers
- Food and drink vocabulary
- Basic location sentences

Core vocabulary
- `waan` - I, short focused form
- `waxaan` - I, used before a fuller statement
- `akhriyayaa` - read / am reading
- `cunayaa` - eat / am eating
- `ordayaa` - run / am running
- `buug` - book
- `bariis` - rice
- `beerta` - the park / garden
- `Denmark` - Denmark

Rule
Beginner rule: use `waan` when the sentence is short and direct.

Use `waxaan` when the sentence has an object, a place, or another extra part.

Teacher note
This is a production shortcut for early lessons, not a universal rule. Later lessons can introduce `baa`, `ayaa`, `wuu`, `way`, and richer focus patterns.

Comparison phrases
- `Waan akhriyayaa.` - I read.
- `Waxaan akhriyayaa buug.` - I read a book.
- `Waan cunayaa.` - I eat.
- `Waxaan cunayaa bariis.` - I eat rice.
- `Waan ordayaa.` - I run.
- `Waxaan ordayaa beerta.` - I run in the park.
- `Waxaan joogaa Denmark.` - I live / am in Denmark.

Common mistake
- Avoid `Waan akhriyayaa buug.`
- Use `Waxaan akhriyayaa buug.`

Practice prompts
- I read. -> `Waan akhriyayaa.`
- I read a book. -> `Waxaan akhriyayaa buug.`
- I eat. -> `Waan cunayaa.`
- I eat rice. -> `Waxaan cunayaa bariis.`
- I run. -> `Waan ordayaa.`
- I run in the park. -> `Waxaan ordayaa beerta.`

Notes for YAML
- Best implemented as a `grammarTable` skill.
- Include a study slide first, then a checked practice table.
- Practice rows should ask for the whole Somali sentence, not just `waan` or `waxaan`.
- Keep examples close to current course vocabulary: food, books, places, family, and daily life.
- Start with paired examples so the learner sees one variable changing at a time.
- Add a final "avoid this" row only after several correct examples; do not lead with errors.
- Accept the taught beginner forms even where a more fluent speaker might choose `baan` or another focus marker.
