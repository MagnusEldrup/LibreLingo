# Lesson 19: Oral Drill: Translate Quickly

Module: Review
Suggested skills: `oral_drill_translate_quickly`, `quick_sentence_production`
Source material: `Chatbot_1.pdf`, pages 11-13

Focus
Create short prompt sets that can be read aloud and answered quickly, while still being checkable in the app.

Why this lesson exists
The learner specifically asked for normal sentences and questions that can be answered aloud. In the app, this should still be checkable, but the content should feel like quick spoken recall.

Prerequisites
- `waan` vs `waxaan`
- Food production
- `Waxaan rabaa inaan...`
- Past vs present

Core vocabulary
- `cunayaa` - eat / am eating
- `akhriyayaa` - read / am reading
- `joogaa` - am located / staying
- `jecelahay` - like
- `rabaa` - want
- `buug` - book
- `magaalada` - the city
- `qoyska` - the family
- `shaah` - tea

Prompt set 1: quick translation
- I eat. -> `Waan cunayaa.`
- I eat rice. -> `Waxaan cunayaa bariis.`
- I am in the city. -> `Waxaan joogaa magaalada.`
- I like coffee. -> `Waan jeclahay bun.`
- I want to drink tea. -> `Waxaan rabaa inaan cabbo shaah.`

Prompt set 2: choose the right shape
- I read. -> `Waan akhriyayaa.`
- I read a book. -> `Waxaan akhriyayaa buug.`
- I want to eat. -> `Waxaan rabaa inaan cuno.`
- I like my family. -> `Waan jeclahay qoyskayga.`
- I live in Denmark. -> `Waxaan joogaa Denmark.`

Prompt set 3: answer questions
- `Magacaa?` -> `Magacaygu waa ...`
- `Xaggee joogtaa?` -> `Waxaan joogaa ...`
- `Maxaad jeceshahay?` -> `Waan jeclahay ...`
- `Maxaad rabtaa?` -> `Waxaan rabaa ...`
- `Xaggee ayaad tagtay shalay?` -> `Shalay waxaan tagay ...`

Notes for YAML
- The app should present these as checkable typed or chip prompts, not self-graded oral prompts.
- The lesson title can signal speaking practice, but the interaction still needs fixed answers.
- Use this as a review checkpoint after Daily Basics and before Travel.
- Keep each practice run short and shuffled.
- Best challenge mix: one screen of chips, then short input, then a conversation-style recap.
- Do not introduce new vocabulary. This is a fluency lesson, not a content lesson.
